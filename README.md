Premium Corporate Website Prompt for Lovable

Project Overview

Create a premium, luxury, modern B2B corporate website for a commercial vehicle diagnostics and workshop technology company.

The website should feel comparable to Bosch Automotive, Mercedes-Benz Trucks, Volvo Trucks, Caterpillar, or Siemens—not like a typical garage or workshop website.

This website is a standalone company website that is associated with ADL Automotive. It should have its own branding while subtly mentioning that it is powered by or backed by ADL Automotive for credibility.

The objective is to build trust immediately and convert visitors into enquiries.

The design should focus on premium quality, clean spacing, elegant typography, smooth animations, and excellent mobile responsiveness.

Do not create a generic template.

Do not use boxed layouts everywhere.

Use large visual sections with plenty of breathing space.
